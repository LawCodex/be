# 12 JUIN 1992. - Loi portant confirmation du Code des impôts sur les revenus 1992, coordonné le 10 avril 1992.

## Art. 1

Article unique. Le Code des impôts sur les revenus 1992, coordonné par l'arrêté royal du 10 avril 1992, est confirmé.

Il s'applique à partir de l'exercice d'imposition 1992.

## Art. N

Le texte coordonné, confirmé par cette loi, paraît en supplément au Moniteur belge de ce jour, sous les folios - 1 - à - 221 -. &lt;Pour le texte, voir C.N. : 1992-04-10/32&gt;
